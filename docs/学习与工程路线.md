# 技术主题索引

目录按技术主题组织；`practice/` 保存维护者独立实现，综合软件模块另外提供 `tests/` 主机测试。

| 主题 | 代码与分析入口 | 关注点 |
| --- | --- | --- |
| C 语言基础 | 程序、数据类型、数组与字符串 | 类型宽度、控制流、数组长度与存储形式 |
| C 语言核心 | 指针、动态内存、结构体、文件 I/O | 地址传递、资源生命周期、失败路径 |
| 程序设计 | 多文件、接口与回调 | 声明/实现分离、模块状态与调用方向 |
| C++ 程序设计 | 类、封装、STL | 对象不变式、构造与容器边界 |
| 嵌入式软件思想 | 分层、驱动接口、状态机 | 将主机端设计方法迁移到资源受限系统时的边界 |

## 实践入口

- [数组实践](../projects/01_C语言基础能力/数组与字符串/practice/array_sum.c)把长度与溢出检查纳入接口。
- [缓冲区实践](../projects/02_C语言核心能力/动态内存管理/practice/int_buffer.c)与[记录读写实践](../projects/02_C语言核心能力/文件IO/practice/checked_records.c)覆盖资源生命周期、错误返回与释放路径。
- [计数器实践](../projects/03_程序设计能力/多文件工程设计/practice/main.c)用头文件、实现文件与入口文件展示模块状态封装。
- [C++ 封装实践](../projects/04_C++程序设计/封装设计/practice/main.cpp)通过构造参数与成员函数维护状态约束。
- [按键状态机实践](../projects/05_嵌入式软件思想/状态机思想/practice/main.c)是主机端事件/状态逻辑示例，用于解释输入状态管理，不是 MCU 板上测试记录。

## 综合软件实践

Command Framework、Ring Buffer、Task Manager 与 Firmware Console 展示固定容量、显式错误状态、模块组合与失败路径验证。主机编译和测试方式见[编译环境说明](编译环境说明.md)。历史课程资料不包含在当前公开仓库中。
