# 学习与工程路线

V1 从已存在的课程练习中挑出三个可以直接读代码的节点。

1. **数据如何跨函数传递**：`c-pointer-memory` 对照交换函数的值形参与指针形参。前者只改到形参副本，后者通过解引用写回调用者变量；堆内存例子进一步引入申请、判空与释放。
2. **实现如何跨文件组织**：`c-module-design` 把 `sayHi` 的声明放在 `calc.h`，实现放在 `calc.c`，调用保留在 `main.c`。`A.h`、`B.h` 则展示 include guard 与间接包含，同时暴露“在头文件中定义全局变量”这一后续应谨慎处理的写法。
3. **数据与行为如何放进类**：`cpp-class-object` 用 `stu.h` 描述对象接口，在 `stu.cpp` 实现 `read()`，由 `main.cpp` 创建对象。原类成员全部公开，因此它展示的是类的基本组织和头源分离，而不是完整的数据隐藏设计。

这三步对应嵌入式软件开发中常见的基础问题：谁拥有数据、模块之间如何调用、接口与实现如何分开。它们本身仍是主机端课程程序，不等于已经实现 MCU 驱动或硬件抽象。

后续路线以实际施工为准：先验证并记录这三个案例，再从现有结构体、文件 I/O、回调练习中选择一个问题写个人改进版本，并注明原版与改进点。状态机、多态和硬件抽象等主题尚不在 V1 已完成清单中。
