# 调试方法与已遇到的问题

## 一次改动怎样验证

1. 确认要验证的是 `course/` 原版还是 `practice/` 个人版本，不混编多个带 `main` 的例子。
2. 从仓库根目录构建到 `.build/`，记录编译器、参数、警告和退出码；个人代码使用 `-Werror`。
3. 用正常路径和至少一个错误路径运行。若程序写文件，工作目录设为 `.build/`，结束后清理测试数据。
4. 对照源文件与文档核查结果，不因输出符合预期就推断所有边界已通过。

## 当前可复查的记录

- Windows GCC/G++ 16.1.0 在本地中文绝对输出路径下曾使链接器找不到目标文件；从仓库根目录使用相对 `-o .build/name.exe` 后构建成功。
- GBK 编码的 C++ 示例使用 `-finput-charset=GBK` 构建；`practice/` 文件统一使用 UTF-8。
- 课程 `vector` 循环有有符号/无符号比较警告，字符串练习有未使用变量警告；保留原版，在主题文档说明。
- 文件 I/O 示例从临时路径读回两条记录；指定不存在的目录时返回错误码 1。当前文件格式为文本记录。
- 主机端状态机用短按和长按两条事件序列验证转换；没有板上按键或时间测量。

实际硬件实验的串口、波形、照片和烧录记录尚不属于本仓库当前验证结果。
