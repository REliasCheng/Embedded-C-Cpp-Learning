# 代码规范与来源

`course/` 与 `practice/` 使用不同的维护规则。

## course

`course/` 中的源文件保留原始文件名、注释、编码与换行；不因编译警告或风格偏好直接修改。课程原版可能含固定长度、未检查返回值或公开字段，问题写进主题文档。`.gitattributes` 对这些目录关闭文本转换，避免 Git 改写原文件字节。

## practice

个人代码放在对应主题的 `practice/`，用清楚的函数参数表达长度、所有权和失败路径。C 代码按 C11 构建，C++ 代码按 C++11 构建；新代码应通过 `-Wall -Wextra -Werror -pedantic`。测试不能靠修改课程源码取得通过。

头文件只暴露必要声明，内部状态优先放在 `.c/.cpp` 中；资源申请、打开和释放由明确的一方负责。测试记录写明工具链和运行环境。
