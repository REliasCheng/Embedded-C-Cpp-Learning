# C 语言能力与嵌入式开发的连接

| 仓库中的真实代码 | 可以支持的工程判断 | 不能直接推出 |
| --- | --- | --- |
| [定宽整数与位运算](../projects/01_C语言基础能力/README.md) | 字段宽度、位掩码应在接口中明确 | 已验证某芯片寄存器行为 |
| [数组长度实践](../projects/01_C语言基础能力/数组与字符串/practice/array_sum.c) | 缓冲区地址必须配合有效长度 | 已实现 DMA 或串口缓冲区 |
