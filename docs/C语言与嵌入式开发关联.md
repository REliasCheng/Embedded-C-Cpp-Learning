# C 语言能力与嵌入式开发的连接

| 仓库中的真实代码 | 可以支持的工程判断 | 不能直接推出 |
| --- | --- | --- |
| [定宽整数与位运算](../projects/01_C语言基础能力/README.md) | 字段宽度、位掩码应在接口中明确 | 已验证某芯片寄存器行为 |
| [数组长度实践](../projects/01_C语言基础能力/数组与字符串/practice/array_sum.c) | 缓冲区地址必须配合有效长度 | 已实现 DMA 或串口缓冲区 |
| [指针与堆内存](../projects/02_C语言核心能力/README.md) | 数据所有权、失败返回和释放路径要可检查 | MCU 上适合动态分配 |
| [多文件与回调](../projects/03_程序设计能力/README.md) | 调用方、接口和实现可分离 | 已完成实时调度器 |
| [主机端状态机](../projects/05_嵌入式软件思想/状态机思想/docs/转换与测试.md) | 状态转换可以脱离硬件 I/O 单独测试 | 已验证按键消抖或定时精度 |

这些联系是基于源码的设计分析。要把它们变成真实驱动，还需目标板原理图、引脚和外设配置、时序/资源预算，以及板上调试证据。本仓库与 [STC89C52RC 实验仓库](https://github.com/REliasCheng/stc89c52-learning)侧重点不同：这里证明语言与软件结构基础，硬件工程留在对应仓库。
