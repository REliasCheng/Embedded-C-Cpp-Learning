# 工程结构设计

第一层按 C 基础、C 核心、程序设计、C++ 和嵌入式软件结构组织。当前公开仓库仅保留维护者编写的实践源码、测试与技术文档。

```text
projects/<topic-group>/<topic>/
  practice/  可独立构建的个人实现
  tests/     适用模块的主机端测试
```

仓库根目录中的 `docs/` 记录构建、设计与调试方法，`scripts/` 提供可重复的主机端测试入口，`.github/workflows/` 执行 GCC / Clang CI。

普通实践示例通常拥有各自的 `main`，需要按案例单独编译。综合软件实践把可复用实现与测试入口分开。真实入口、依赖和命令见[编译环境说明](编译环境说明.md)；`.build/`、临时数据和安装包不进入 Git。
