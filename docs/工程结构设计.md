# 工程结构设计

第一层按 C 基础、C 核心、程序设计、C++ 和嵌入式软件结构组织。day01–day13 保留在 `docs/来源-dayXX.md` 与课程原始路径中。

```text
projects/<topic-group>/<topic>/
  course/    精选课程原版；存在时保持字节不变
  practice/  实际完成的个人版本或主机端测试
  docs/      原课程阶段记录与技术差异
```

某个主题只在存在对应内容时建立 `course/`、`practice/` 或 `docs/`。

V1 的三组专题源码分别并入 [多文件工程设计](../projects/03_程序设计能力/多文件工程设计/docs/V1多文件专题.md)、[指针与地址访问](../projects/02_C语言核心能力/指针与地址访问/docs/V1指针与内存专题.md) 和 [类与对象](../projects/04_C++程序设计/类与对象/docs/V1类与对象专题.md)；原说明保存在主题 `docs/`，课程源码没有复制第二份。

各课堂练习通常自带 `main`，需要按案例单独编译。个人实践的入口、依赖和命令见对应主题及[编译环境说明](编译环境说明.md)。`.build/`、临时数据和安装包不进入 Git。
