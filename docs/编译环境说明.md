# 编译环境说明

本次验证环境为 Windows PowerShell、GCC/G++ 16.1.0。命令从仓库根目录执行，把输出放在已被 `.gitignore` 排除的 `.build/`。每个课堂练习通常自带 `main`，只编译当前案例所需源文件。

```powershell
New-Item -ItemType Directory -Path .build -Force | Out-Null

# 课程原版：C 多文件
gcc -std=c11 -Wall -Wextra -pedantic `
  projects/03_程序设计能力/多文件工程设计/course/hello-module/main.c `
  projects/03_程序设计能力/多文件工程设计/course/hello-module/calc.c `
  -o .build/course-module.exe

# 课程原版：C++ GBK 源码
g++ -std=c++11 -Wall -Wextra -pedantic -finput-charset=GBK `
  projects/04_C++程序设计/类与对象/course/class-separate/main.cpp `
  projects/04_C++程序设计/类与对象/course/class-separate/stu.cpp `
  -o .build/course-class.exe

# 个人实践：独立 C 程序
gcc -std=c11 -Wall -Wextra -Werror -pedantic `
  projects/01_C语言基础能力/数组与字符串/practice/array_sum.c `
  -o .build/array_sum.exe
./.build/array_sum.exe
```

其他 `practice/` 案例中，`counter`、`Student` 和状态机均有多个源文件，编译时须把实现文件一起传给编译器。`checked_records` 需要一个显式的输出文件参数，建议在 `.build/` 中指定测试路径。测试入口使用 `assert`，应在未定义 `NDEBUG` 的构建中运行。

当前验证只覆盖列出的主机端工具链。Keil、交叉编译器、Linux、不同 C++ 标准库以及真实 MCU 目标都尚未在此仓库验证。
