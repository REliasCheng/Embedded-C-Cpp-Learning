# Diagrams

`images/architecture/` 保存与源码结构对应的架构图。

当前包含：

- `images/architecture/command-framework-architecture.svg`：对应命令框架的字节输入、环形缓冲、解析、回调和设备状态路径。
- `images/architecture/task-manager-architecture.svg`：对应任务表、tick、状态过滤、回调和运行计数路径。

添加媒体时请写明对应代码版本、设备/工具、拍摄或录制时间及画面内容。体积较大的视频优先使用 GitHub Release 或外部链接，不直接塞进普通 Git 历史。
