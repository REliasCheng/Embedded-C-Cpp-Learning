# 主机端按键事件状态机

[实践源码](../practice/key_fsm.h)将状态定义为 `IDLE`、`PRESSED`、`HELD`，事件定义为 `PRESS`、`RELEASE`、`TICK`。

| 当前状态 | 事件与条件 | 下一状态 | 返回 |
| --- | --- | --- | --- |
| IDLE | PRESS | PRESSED | false |
| PRESSED | RELEASE，累计不足 3 次 TICK | IDLE | true，短按完成 |
| PRESSED | 第 3 次 TICK | HELD | false |
| HELD | RELEASE | IDLE | false |

其他组合不改变状态。`main.c` 用短按与长按两条序列进行断言；本机编译运行通过。阈值 3 是离散事件计数，不是毫秒值，也没有做物理按键消抖。将来接板时应让输入层产生稳定事件，状态机本身不直接读 GPIO。
