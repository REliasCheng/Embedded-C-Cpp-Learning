# 从多文件练习推导调用层次

[多文件工程课程原版](../../../03_程序设计能力/多文件工程设计/docs/V1多文件专题.md)具有 `main.c → calc.h → calc.c` 的调用关系；[个人 counter](../../../03_程序设计能力/多文件工程设计/practice/counter.c)把内部状态限制在实现文件。它们能支持“应用入口依赖公开接口，而不直接拥有内部状态”的设计判断。

如果日后接入板级代码，可把应用决策、设备接口、硬件访问分层，并为每层定义数据流和错误返回。但本仓库目前没有这三层完整的 MCU 工程，本页不把语言练习写成现有硬件架构。
