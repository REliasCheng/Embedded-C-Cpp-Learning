# 语言机制如何进入软件结构

课程示例保留了语言机制最小用法，`practice/` 再把这些机制组合到可构建程序中。下面的入口对应当前仓库中的实际关系。

| 语言机制 | 课程入口 | practice 中的用法 |
| --- | --- | --- |
| 定宽整数与位运算 | [数据表示](../../01_C语言基础能力/数据类型与内存模型/docs/来源-day02.md)、[位运算](../../01_C语言基础能力/程序入口与控制流/docs/来源-day03.md) | 状态值和错误码使用明确宽度，位标志通过掩码读写 |
| 指针与数组长度 | [指针专题](../../02_C语言核心能力/指针与地址访问/docs/V1指针与内存专题.md)、[数组接口](../../01_C语言基础能力/数组与字符串/docs/来源-day06.md) | 环形缓冲区同时维护存储地址、容量、读位置和写位置 |
| 头文件与多文件工程 | [多文件专题](../../03_程序设计能力/多文件工程设计/docs/V1多文件专题.md)、[函数接口](../../03_程序设计能力/模块化接口设计/docs/来源-day04.md) | command、device、ring_buffer 和 task 各自提供头文件接口 |
| 函数指针与枚举 | [回调](../../03_程序设计能力/函数指针与回调/docs/来源-day05.md)、[枚举](../../02_C语言核心能力/结构体与数据组织/docs/来源-day08.md) | 命令表和任务表保存回调，枚举限制设备或任务状态 |
| 类与构造函数 | [类与对象](../../04_C++程序设计/类与对象/docs/来源-day13.md) | 构造阶段建立对象初始状态，接口隐藏成员数据 |

完整组合示例位于[嵌入式命令处理框架](../../06_综合软件实践/嵌入式命令处理框架/README.md)和[轻量任务状态管理](../../06_综合软件实践/轻量任务状态管理/README.md)。状态转换的独立测试见[转换与测试](../状态机思想/docs/转换与测试.md)。
