# vector 容器的增删改查（day11）

这个课堂例子围绕 `std::vector<int>` 完成追加、修改、遍历和删除，作为后续理解容器接口与边界的起点。

## 主题

`push_back` 在尾部追加；`at` 访问时进行边界检查；`operator[]` 不做同样的检查；`erase(scores.begin())` 删除首元素并使后续位置移动。

## 文件

[课程原版](../course/vector/02_main.cpp)来自 `day11-c++/上课代码.rar` 内的 `day02/05_vector/02_main.cpp`。全部操作集中在 `main`，没有自定义容器或算法模块。

## 代码说明

原例先把索引 0、1 改为 55、56，再遍历输出；删除首元素后再次遍历。两轮循环用 `int i` 比较 `scores.size()`，本机编译器因此报告有符号/无符号比较警告。

访问方式决定边界保护，删除操作会影响索引和迭代器。在资源受限环境中使用容器时，还需要评估动态分配成本。

## 构建记录

使用 G++ 16.1.0 和 GBK 输入编码编译运行通过，退出码 0；编译器报告两处 `-Wsign-compare` 警告。故意越界的演示文件不在本次运行范围内。
