# C++ 类与对象实践

这个课程案例用三个文件展示类声明、成员函数实现和对象使用。原代码来自 day13 的课堂 RAR；只迁入该案例的 `main.cpp`、`stu.cpp`、`stu.h`，没有解压或上传整个教学工程。

## 类的组织

C++ 类可以把数据和操作这些数据的函数放在同一个类型中。`stu.h` 声明成员，`stu.cpp` 使用 `stu::read()` 定义行为，`main.cpp` 创建对象并调用。课程版本的 `name` 和 `age` 都是 `public`。

## 文件

```text
main.cpp ──include──> stu.h ──声明──> class stu / read()
    │                                 ↑
    └────创建对象并调用 s.read()──────┤
stu.cpp ──include──> stu.h ──实现──────┘
```

源码保留课程压缩包条目的来源记录；仓库内置于 `course/class-separate/`。`stu.h` 使用头文件保护宏；原版在头文件中写 `using namespace std;`，这会把命名空间影响带给包含它的文件，仓库不替课程源码改写。

## 构造函数与成员

- `class stu` 定义 `name`、`age` 与 `read()`；该类的成员当前全部公开。
- `stu::read()` 中的作用域限定符把实现绑定到 `stu`，输出该对象当前的年龄和姓名。
- `main()` 创建栈上对象 `s`，设置两个成员，再调用 `s.read()`。这说明成员函数对同一个对象状态的访问方式，而不是继承或多态案例。

原文件使用 GBK 编码。从仓库根目录构建：

```powershell
New-Item -ItemType Directory -Path .build -Force | Out-Null
g++ -std=c++11 -Wall -Wextra -pedantic -finput-charset=GBK projects/04_C++程序设计/类与对象/course/class-separate/main.cpp projects/04_C++程序设计/类与对象/course/class-separate/stu.cpp -o .build/cpp-class-object.exe
./.build/cpp-class-object.exe
```
