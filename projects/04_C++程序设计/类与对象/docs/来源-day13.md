# 类对象与构造函数（day13）

本目录补充类的无参/有参构造练习；V1 的 [类头源分离案例](V1类与对象专题.md)继续展示 `stu.h / stu.cpp / main.cpp` 的文件组织。

## 主题

对象创建时按所给参数选择构造函数。无参构造写入默认姓名和年龄，有参构造用传入的姓名与年龄建立另一个对象。

## 文件

[构造函数原版](../course/constructors/07_main.cpp)来自 `day13-c++/上课代码.rar` 内的 `day04/02_class_object/07_main.cpp`。单文件 `main` 分别创建 `s1`、`s2`；头源分离示例位于 V1 原目录，不重复复制。

## 代码说明

`stu s1;` 触发无参构造；`stu s2("李四", 19);` 触发有参构造。原类的 `name`、`age` 为公开成员，因此该例聚焦构造与对象状态初始化；封装设计见相邻专题。

构造函数建立对象的初始状态。本例覆盖基础对象生命周期；跨文件类设计、访问控制和资源所有权在其他专题中展开。

## 构建记录

G++ 16.1.0 指定 GBK 输入编码后编译运行通过，输出两次构造提示及 `李四=19`，退出码 0。
