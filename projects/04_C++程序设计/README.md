# C++ 程序设计

## 项目简介

从标准流和引用进入对象、构造与容器；把课程原版类与一个独立的私有成员实践分开，避免把课堂类误写成完整封装设计。

## 技术背景

C++ 类型既要组织数据和操作，也要明确对象初始化、可见性及容器访问边界。是否适用于嵌入式目标，还需考虑工具链与资源。

## 核心实现

课程 `stu` 把字段公开；个人 `Student` 将字段设为 `private`，通过构造函数和 `set_age` 控制无效状态。实现文件与头文件分开，测试覆盖无效构造和负年龄更新。

## 关键代码分析

`stu::read()` 展示成员实现的作用域；`Student::set_age` 则把状态变更集中到接口。`vector::at` 和下标访问的边界处理不同；原容器练习仍保留其有符号/无符号比较警告。

## 调试记录

课程 C++ 原文件使用 GBK，先前测试指定 `-finput-charset=GBK`。个人代码为 UTF-8，G++ 16.1.0 在 `-Wall -Wextra -Werror -pedantic` 下编译运行通过，输出 `Zhang age=19`。

## 嵌入式关联

对象初始化和接口约束有助于表达设备状态，但异常、动态字符串和 `vector` 的可用性取决于目标编译器、内存预算与项目约束；这些主机端例子不能直接当作 MCU 最佳实践。
