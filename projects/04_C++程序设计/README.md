## Student 的两个实现

参考类 `stu` 公开字段；`practice/` 中的 `Student` 将字段设为 `private`，通过构造函数和 `set_age` 控制无效状态。实现文件与头文件分开，测试覆盖无效构造和负年龄更新。

### 作用域与边界

`stu::read()` 展示成员实现的作用域；`Student::set_age` 则把状态变更集中到接口。`vector::at` 和下标访问的边界处理不同；原容器练习仍保留其有符号/无符号比较警告。

## 构建与测试

GBK 编码示例使用 `-finput-charset=GBK` 构建。`practice/` 代码采用 UTF-8，G++ 16.1.0 在 `-Wall -Wextra -Werror -pedantic` 下编译运行通过，输出 `Zhang age=19`。

## 目标平台约束

对象初始化和接口约束可用于表达设备状态；在 MCU 上使用异常、动态字符串或 `vector` 前，还需要核对编译器支持和内存预算。
