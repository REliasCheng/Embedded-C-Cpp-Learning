# C++ 标准输出与作用域（day10）

进入 C++ 阶段后，课程用 `std::cout` 和 `std::endl` 演示标准输出；本目录保留一个单文件例子，不把它包装为独立应用。

## 主题

`std::` 指明名字属于标准库命名空间；`std::cout` 接收流式输出，`std::endl` 同时换行并刷新缓冲区。普通 `"\n"` 仅表示换行。

## 文件

[课程原版](../course/iostream/main.cpp)来自 `day10-c++/代码/code.rar` 内的 `05_input_output/main.cpp`，只有 `main` 和标准库调用。

## 代码说明

前两次输出使用字符串中的换行符，后续输出使用 `std::endl`。这里说明语法与输出路径，不涉及设备串口或 MCU 标准输出重定向。

我把从 C 的 `printf` 转到 C++ 流看作表达方式变化，而不是嵌入式程序必须使用 iostream。选择输出机制仍取决于目标平台与资源约束。

## 构建记录

原文件为 GBK 编码。本次用 G++ 16.1.0 指定 `-finput-charset=GBK` 后编译运行通过，退出码 0，终端显示四行文本。
