# 引用与对象别名（day12）

## 内容介绍

该练习让 `age02` 引用 `age`，通过两次地址打印和一次赋值观察两个名字指向同一对象的关系。

## 核心知识

`int &age02 = age` 在声明时绑定原对象；之后给 `age02` 赋值会改变 `age`。引用的语法比裸指针简洁，但接口设计仍要说明参数是否可修改。

## 代码结构

[课程原版](../course/reference/01_main.cpp)来自 `day12-c++/上课代码.rar` 内的 `day03/03_reference/01_main.cpp`。全部验证在单个 `main` 中完成。

## 关键实现

`&age` 与 `&age02` 在同次运行中打印相同地址；`age02 = 19` 后 `age` 输出 19。地址的具体数值不是稳定测试结果。

## 工程意义

我将引用理解为接口里的别名关系。它便于表达“此参数对应已有对象”，但是否允许修改、对象是否仍存活，仍要由类型和调用约定约束。
