# 从公开字段到受控状态

课程 [`stu` 类](../../类与对象/course/class-separate/stu.h)公开 `name` 和 `age`，便于入门展示对象与成员函数，但调用方可直接写入不合理的值。

个人 [`Student`](../practice/student.hpp) 把两个字段设为 `private`；构造函数拒绝空姓名和负年龄，`set_age` 拒绝负值。测试在主机端覆盖有效对象、无效更新和构造失败。头文件声明与源文件实现分离，没有修改课程 `stu`。

本例使用 `std::string` 与异常；资源受限嵌入式目标是否可接受这些特性，必须另行评估。
