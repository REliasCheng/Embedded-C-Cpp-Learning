# 综合软件实践

这一组项目把指针、固定缓冲区、结构体、回调、接口封装和状态机组合成可独立构建的主机端程序，代码位于 `practice/`。

| 项目 | 实现 | 测试入口 |
| --- | --- | --- |
| [嵌入式命令处理框架](嵌入式命令处理框架/README.md) | 环形缓冲区、逐字节输入、命令表、回调分发、错误返回 | `tests/test_command_framework.c` |
| [轻量任务状态管理](轻量任务状态管理/README.md) | 固定任务表、周期 tick、状态转换、故障隔离、回调执行 | `tests/test_task_manager.c` |

两个项目都避免动态分配：容量、输入长度和任务数量在接口中明确给出，便于以后替换主机端输入为 UART ISR、替换模拟 tick 为 MCU 定时中断。
