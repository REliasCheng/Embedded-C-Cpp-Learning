# 位运算与分支选择（day03）

## 内容介绍

选取按位与和 `switch` 两个练习：前者处理二进制位，后者按输入选择执行路径。它们对应后来分析状态位与分支逻辑所需的基础语义。

## 核心知识

`3 & 5` 保留两个操作数同为 1 的位；`switch` 用 `case` 匹配输入，每个分支通过 `break` 结束。原例还对负数执行按位与，解读结果时应注意整数表示与平台。

## 代码结构

[位运算原版](course/01_位运算 - 与运算.c)和 [分支原版](course/13_条件控制 - switch.c)均来自 `day03/03_代码/`，各有独立 `main`，不能一起链接。

## 关键实现

按位与例子把计算结果保存到 `int8_t` 再打印。分支例子用 `scanf("%c", &level)` 读取一个字符，`A` 到 `D` 对应四种输出，其余走 `default`。

## 工程意义

我在这里区分了“对位做变换”和“按条件调度代码”。嵌入式程序中它们经常相邻出现，但位掩码、输入校验和分支覆盖仍是不同的设计问题。

## 调试记录

两个程序分别编译运行通过。位运算例子在本机输出 `a=1`、`b=-55`；分支例子输入 `A` 后输出“优秀”，退出码均为 0。其他输入分支未在本次逐一测试。
