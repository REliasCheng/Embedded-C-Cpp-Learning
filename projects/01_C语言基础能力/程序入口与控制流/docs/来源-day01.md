# 程序入口与标准输出（day01）

这个最小 C 程序连接 `main`、头文件、标准输出和返回值，是后续案例的构建起点。

## 主题

`#include <stdio.h>` 提供输出函数声明；程序由 `main()` 开始，依次输出三行，最后返回 0。

## 文件

[课程原版](../course/first-program/01_第一个程序.c)只有一个源文件，原位置为 `day01/03_代码/01_第一个程序.c`。调用链是 `main → printf`。

## 代码说明

三次 `printf` 的换行由字符串中的 `\n` 决定。没有额外的硬件外设或驱动层。

该例覆盖“源码 → 编译链接 → 进程执行”的最小闭环；后续练习沿用相同方式记录入口和输出。

## 构建记录

使用 GCC 16.1.0 单独编译运行，输出 `123`、`456`、`789`，退出码 0。
