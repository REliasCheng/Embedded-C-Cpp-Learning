# 程序入口与标准输出（day01）

从一个可执行的 C 程序确认 `main`、头文件、`printf` 和返回值的关系。它是后续案例的构建起点，不作为独立工程成果夸大展示。

## 主题

`#include <stdio.h>` 提供输出函数声明；程序由 `main()` 开始，依次输出三行，最后返回 0。

## 文件

[课程原版](../course/first-program/01_第一个程序.c)只有一个源文件，原位置为 `day01/03_代码/01_第一个程序.c`。调用链是 `main → printf`。

## 代码说明

三次 `printf` 的换行由字符串中的 `\n` 决定。没有额外的硬件外设或驱动层。

我以这一例确认“源码 → 编译链接 → 进程执行”的最小闭环；后面每个练习都应能独立说明入口和输出，而不只是有一份 `.c` 文件。

## 构建记录

本次用 GCC 16.1.0 单独编译运行，输出 `123`、`456`、`789`，退出码 0。没有修改课程代码。
