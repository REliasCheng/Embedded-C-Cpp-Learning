# 定宽整数与数据表示（day02）

## 内容介绍

课程从基本类型推进到 `stdint.h` 中的定宽整数。这个例子打印 `int8_t`、`int16_t`、`int32_t` 的字节数。

## 核心知识

当协议字段或存储布局要求明确的位宽时，不能只凭 `int`、`long` 在某台电脑上的长度推断所有平台；定宽类型让约束写进声明。

## 代码结构

[课程原版](course/07_数据类型 - 可移植类型.c)位于 `day02/03_代码/07_数据类型 - 可移植类型.c`。单文件 `main` 依次声明三个变量并输出 `sizeof`。

## 关键实现

`sizeof(a)` 的单位是字节，示例用 `%zu` 打印。这里展示的是类型尺寸，不是跨平台传输格式或字节序的完整处理。

## 工程意义

我把“选类型”理解为接口约束的一部分：嵌入式寄存器、通信字段和文件布局往往需要先明确宽度，再考虑取值范围和平台差异。

## 调试记录

本机 GCC 16.1.0 编译运行通过，依次输出 1、2、4 字节，退出码 0。这个结果只对应当前工具链。
