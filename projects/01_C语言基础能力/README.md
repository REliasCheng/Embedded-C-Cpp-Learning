## 数组实践

`course/` 中的数组函数只接收首元素地址，循环次数固定为 5。`practice/` 版本增加 `count` 参数，并对空指针和求和溢出返回失败。

### 长度与存储

`sizeof values / sizeof values[0]` 在调用点得到当前数组长度；函数内部只使用显式传入的 `count`。字符数组例子则区分修改数组内容与重新指定指针地址。[示例来源](数组与字符串/docs/来源-day07.md)记录文件对应关系。

## 构建与测试

参考示例已分别在 GCC 16.1.0 编译运行。`array_sum.c` 以 `-Wall -Wextra -Werror -pedantic` 构建，并通过非空、空数组和无效指针测试。

## 嵌入式接口中的用法

定宽类型和位掩码用于表达寄存器与协议字段；显式缓冲区长度用于限制越界风险。本组使用主机环境验证语言和接口行为。
