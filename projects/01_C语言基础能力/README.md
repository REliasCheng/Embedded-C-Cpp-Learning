## 数组实践

课程的数组函数只接收首元素地址，循环次数固定为 5。个人版本增加 `count` 参数并对空指针和求和溢出返回失败，源码单独置于 `practice/`，不覆盖课程原版。

### 长度与存储

`sizeof values / sizeof values[0]` 在调用点得到当前数组长度；函数内部只相信显式传入的 `count`。字符数组例子则区分修改数组内容与重新指定指针地址。[课程边界记录](数组与字符串/docs/来源-day07.md)保留原练习语境。

## 构建与测试

课程精选例子已分别在 GCC 16.1.0 编译运行。`array_sum.c` 以 `-Wall -Wextra -Werror -pedantic` 构建，并通过非空、空数组和无效指针测试。

## 嵌入式接口中的用法

定宽类型和位掩码是寄存器/协议字段的语言基础；显式缓冲区长度有助于限制越界风险。本组仍是主机端练习，没有访问真实 MCU 寄存器。
