# 字符数组与字符指针（day07）

这个练习对照可修改的字符数组与指向字符串字面量的指针，用地址和输出观察二者的行为。

## 主题

`char c1[] = "abc123"` 在数组里保存字符，`c1[0]` 可修改；`c2` 起初指向字面量，给 `c2` 重新赋地址不等于改写原字面量。原例把字面量赋给 `char *`，现代接口更应考虑 `const char *`。

## 文件

[课程原版](../course/string-storage/03_字符串%20-%20字符指针和字符数组.c)来自 `day07/03_代码/03_字符串 - 字符指针和字符数组.c`。所有操作都在 `main` 中完成；修改字面量的语句只出现在注释中。

## 代码说明

`c1[0] = 'Q'` 改变数组内容；`c2 = "xyz666"` 改变指针指向。原代码用 `%p` 打印地址，地址数值只对当次进程有意义。

我把字符串问题拆成存储位置、可修改性和指针指向三件事。写嵌入式接口时，参数若只读，应通过 `const` 表达意图，而不是依赖调用者记住约定。
