# 数组参数与元素访问（day06）

## 内容介绍

课程用一个五元素数组解释数组传参时的地址关系，同时用指针偏移和下标两种形式读取元素。

## 核心知识

`printArr(int *p)` 接收首元素地址；`*(p+i)` 与 `p[i]` 在这个范围内读取同一个元素。函数并不知道原数组实际长度。

## 代码结构

[课程原版](../course/array-parameter/09_数组%20-%20参数传递数组.c)来自 `day06/03_代码/09_数组 - 参数传递数组.c`。`main` 构造数组并调用 `printArr`，函数内两次循环展示两种访问方式。

## 关键实现

原函数把循环上限固定为 5，与 `main` 中数组长度恰好一致。若调用方换一个长度，这个接口就不可靠；[个人版本](../practice/array_sum.c)已把长度显式传入，课程原版仍保留原样。

## 工程意义

我在这里把“指针能访问元素”和“接口知道有效边界”分开理解。工程函数不能只依赖调用者恰好传来五个元素。
