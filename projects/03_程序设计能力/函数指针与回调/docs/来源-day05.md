# 地址传递与函数回调（day05）

day05 把指针从“保存地址”扩展到“向函数传递数据”和“传递要执行的函数”。V1 的 [值传递/地址传递对照](../../../02_C语言核心能力/指针与地址访问/docs/V1指针与内存专题.md)保留原有练习，这里增加函数指针的实际调用。

## 主题

`check_odd_even` 接受整数和两个函数指针；它判断奇偶，再调用对应回调。调用者负责提供行为，判断函数负责选择时机。

## 文件

[函数指针原版](../course/odd-even/18_指针%20-%20函数指针练习.c)来自 `day05/03_代码/18_指针 - 函数指针练习.c`。关系是 `main → check_odd_even → printOdd / printEven`，没有额外源文件。

## 代码说明

`check_odd_even(13, printOdd, printEven)` 传入函数名作为回调地址。`num % 2 != 0` 为真时调用 `a()`，否则调用 `b()`；判断逻辑不直接写死打印函数。

这是我理解接口“传入策略”的起点：函数指针让调用者和决策逻辑分离。它尚不是任务调度器或硬件中断回调，但机制相通。
