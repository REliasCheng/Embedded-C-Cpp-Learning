# 函数接口与多文件组织（day04）

## 内容介绍

day04 从函数的参数、返回值进入跨文件调用。这里保留“四种函数形式”的课堂练习；V1 的 [C 多文件案例](../../多文件工程设计/docs/V1多文件专题.md)继续承载 `main.c / calc.h / calc.c` 的完整结构分析。

## 核心知识

调用方要知道参数和返回值；跨文件时，头文件提供声明，另一个源文件提供定义。这两个层次不能混为一谈。

## 代码结构

[函数原版](../course/function-signatures/01_函数%20-%20四种形式.c)来自 `day04/03_代码/01_函数 - 四种形式.c`，在单个 `main` 中依次调用无参/有参、无返回值/有返回值的函数。多文件源码已在 V1 单独保存，避免重复复制。

## 关键实现

`sayHi02(int age, char *name)` 通过形参接收数据；`sayHi03()` 返回整数，调用方把结果保存后再打印。多文件案例中的 `sayHi()` 则由 `calc.c` 实现，`main.c` 只依赖 `calc.h` 的声明。

## 工程意义

我把 day04 视为从“写一个函数”转向“定义接口”的节点。函数签名决定调用方式，头文件和链接过程决定模块之间能否协作。
