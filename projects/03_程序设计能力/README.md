## 计数器模块

`counter.h` 只声明函数；`counter.c` 用 `static` 保存模块内部状态，`main.c` 通过公开函数访问。该版本将 `A.h` 中直接定义的全局状态收回实现文件，并增加错误返回。

### 头文件、状态与回调

头文件声明定义调用接口，源文件提供实现。回调例子让调用方选择目标函数；任务队列与周期调度由综合项目中的任务管理器实现。`counter_add` 在更新状态前检查输出指针和整数溢出。

## 构建与测试

多文件和回调示例已分别运行。`counter` 由 GCC 16.1.0 以 `-Wall -Wextra -Werror -pedantic` 编译，正常加减与溢出拒绝路径通过，退出码 0。

## 驱动接口用法

驱动接口通常由头文件向应用层暴露操作，内部状态留在实现文件。这里的 counter 是主机端模块，结构可直接用于讨论驱动 API 的边界。
