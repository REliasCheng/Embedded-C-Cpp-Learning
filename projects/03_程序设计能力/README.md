## 计数器模块

`counter.h` 只声明函数；`counter.c` 用 `static` 保存模块内部状态，`main.c` 通过公开函数访问。它针对原课程 `A.h` 直接定义全局变量的风险写成个人对照版本，而不改课程文件。

### 头文件、状态与回调

头文件声明解决“怎样调用”，源文件定义解决“由谁实现”。回调例子进一步让调用方选择被调用函数，但它没有任务队列或实时调度语义。`counter_add` 在更新状态前检查输出指针和整数溢出。

## 构建与测试

课程多文件和回调示例已分别运行。个人 `counter` 由 GCC 16.1.0 以 `-Wall -Wextra -Werror -pedantic` 编译，正常加减与溢出拒绝路径通过，退出码 0。

## 驱动接口用法

驱动接口通常由头文件向应用层暴露操作，内部状态留在实现文件。这里的 counter 是主机端模块，结构可直接用于讨论驱动 API 的边界。
