# 从固定字节数到受检缓冲区

课程 [堆内存示例](../course/heap/02_内存管理%20-%20堆内存的使用.c)用 `malloc(4)`、判空和 `free` 展示基本生命周期。它的固定字节数不是通用 `int` 尺寸。

个人 [int_buffer.c](../practice/int_buffer.c) 改为 `count * sizeof(int)`，先检查乘法是否超出 `SIZE_MAX`，用 `calloc` 建立零初始化缓冲区；释放函数接收指针地址并置空，避免调用方继续持有已释放地址。测试覆盖普通申请、零长度、过大长度和无效输出参数。

这只证明当前主机端 API 的行为。真实 MCU 是否允许堆分配，仍需由内存布局和实时性要求决定。
