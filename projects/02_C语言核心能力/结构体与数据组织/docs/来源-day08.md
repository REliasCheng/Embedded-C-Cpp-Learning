# 结构体传递与枚举约束（day08）

## 内容介绍

两个练习把数据组织从基本类型推进到结构体和枚举：一个演示返回结构体与传入结构体指针，另一个用枚举限制字段取值。

## 核心知识

`createStudent()` 按值返回一个 `student`；`modifyStudent(&stu)` 通过指针修改同一对象的年龄。`enum Gender` 则让 `Student.gender` 使用离散标识而非任意字符串。

## 代码结构

[结构体与函数](../course/struct-function/09_结构体%20-%20结构体和函数（二）.c)和 [枚举应用](../course/enum/14_枚举%20-%20应用场景.c)来自 `day08/03_代码/`。两者各有独立 `main`，分别编译，不合并为一个工程。

## 关键实现

结构体例子先得到 `stu`，再把 `&stu` 交给 `modifyStudent`，因此修改后的年龄为 29。枚举例子构造 `FEMALE` 数据，用条件表达式把枚举值转换为显示文本。

## 工程意义

我把结构体看作相关字段的统一边界，把枚举看作状态取值的约束。它们是以后整理设备状态、配置或协议数据的基础，但本例还没有实现具体硬件协议。

## 调试记录

两个程序分别编译运行通过：结构体例子由 18 变为 29；枚举例子输出“女”，退出码均为 0。未修改原始定义。
