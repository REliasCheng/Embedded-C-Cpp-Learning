安全访问需要同时处理所有权、有效长度、资源释放和失败返回。

## 受检的分配与 I/O

`int_buffer_create` 先检查输出参数和乘法尺寸，再申请空间；释放函数把调用方指针置空。`checked_records` 检查打开、传输数量和关闭结果，并要求显式提供输出路径。

### 尺寸与布局

原堆内存案例的 `malloc(4)` 隐含类型尺寸假设；个人版本改用 `count * sizeof(int)`，并先判断乘法溢出。原文件案例直接搬运结构体内存，个人版本补足错误路径，但仍沿用本机二进制布局；它不是跨平台文件格式。

## 构建与测试

参考示例已分别构建。两个个人版本在 GCC 16.1.0 下启用警告即错误后构建、运行通过；文件示例另用不存在的目录验证返回错误码 1，正常路径验证两条记录。

## 目标平台约束

分配失败、对象布局和资源释放同样影响嵌入式软件；在不提供堆或文件系统的目标平台上，应重新选择接口实现，不能直接移植主机端代码。
