# 文件 I/O 的失败路径

课程 [结构体数组读写](../course/struct-array/12_文件IO%20-%20读写结构体数组.c)展示 `fwrite/fread` 的基本顺序，但没有检查打开、传输数量和关闭结果。

个人 [checked_records.c](../practice/checked_records.c) 要求调用者传入目标路径，分别检查 `fopen`、`fwrite/fread` 返回数量与 `fclose`。主机端测试用临时路径写入并读回两条记录；把路径指向不存在的目录时，程序返回错误码 1。

该文件仍以本机 `Student` 的内存布局写入二进制数据。结构体填充、整数表示及端序可能变化，所以本改进解决了错误检查，**没有解决跨平台格式问题**。
