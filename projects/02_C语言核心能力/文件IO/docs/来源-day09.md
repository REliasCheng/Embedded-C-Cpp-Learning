# 资源生命周期与结构体文件读写（day09）

day09 的动态内存示例已在 V1 的 [指针与内存案例](../../指针与地址访问/docs/V1指针与内存专题.md)中保存。本目录补入结构体数组的二进制写入和读回，形成“数据 → 文件 → 数据”的路径。

## 主题

`fwrite` 和 `fread` 以 `sizeof(Student)` 为单元搬运连续结构体数组；写完关闭文件，再重新以读取模式打开。原文件格式直接依赖结构体布局，不适合作为跨编译器通用格式。

## 文件

[课程原版](../course/struct-array/12_文件IO%20-%20读写结构体数组.c)来自 `day09/03_代码/12_文件IO - 读写结构体数组.c`。`main` 创建 `stus` 和 `stus2`，写入相对路径 `stus.bin` 后读回并打印。

## 代码说明

`sizeof(stus) / sizeof(Student)` 得到当前数组元素数；`fwrite(stus, sizeof(Student), size, f)` 写入整组记录。原版未检查 `fopen`、`fwrite`、`fread` 的返回值，不能据此宣称异常路径已可靠处理。

我在这里关注文件句柄的获取、使用和关闭，以及数据布局与持久化格式的关系。下一步改进应加入失败检查和可移植格式说明，与课程原版分开放置。
